# 跨期决策偏好形成实验（原型）

## 设计

- 进入全屏后先使用jsPsych 7 virtual-chinrest进行屏幕尺寸和观看距离校准：银行卡尺寸校准后进行3次盲点测量；记录`view_dist_mm`、`px2mm`、`px2deg`等字段，并以视觉角度自动缩放后续页面（`resize_units: "deg"`，每度50像素）。正式选项、说明页和偏好线的最大宽度设为500像素，即校准后不超过10°视觉角度。被试随后需保持相同观看距离。
- 16个condition。时间固定为SS 1周、LL 4周；SS金额为10、20、30、40元，
  每个SS金额与约1.15、1.4、1.8、2.4倍的LL金额配对，以覆盖简单和困难题。
- 正式实验前有5个F/J按键练习trial和5个中途偏好报告练习trial；练习结束后可选择重做整套练习。
- 练习后进行16个初步快速扫视阈限trial。100至1500 ms、间隔200 ms的8个时长各出现两次，并对每位被试随机排列；左右保留双行“X周后 / XX元”。个人初步扫描时间取两个重复都回答“能扫完”的最短时长；一能一不能的时长不作为阈值，若没有任何时长得到两次一致的“能”，则记为1500 ms。
- 初步扫描阈值后使用真实金额和时间进行自适应复核：从初始阈值开始，回答“不能”则增加50 ms，回答“能”则减少50 ms，直到回答首次改变，并且最多进行12题；最终取复核中回答“能”的最短时长。若12题全部回答“不能”，使用本轮测过的最长时长。另设50–3000 ms安全边界。
- Session 1：每个condition出现两次，SS/LL位置翻转，共32 trials；用F/J键选择左/右选项并记录RT。
- Session 2–6：每个condition在0/5、1/5、2/5、3/5、4/5剩余决策时间各出现两次，位置翻转，共160 trials。
- 160个探针trials通过约束随机化分成五个32-trial session；每个session混合五个探针时间。
- 刺激采用“1周后 / 20元”的简洁双行格式。
- 每道中途报告题开始前，被试必须将鼠标移到屏幕中央并点击开始，随后保持在中央。到达询问时间时，金额和时间立即被随机字符视觉掩蔽；被试在1.5秒内移动鼠标到连续偏好横线，圆点跟随鼠标，并以第一次单击的位置直接保存0–100偏好；超时未点击也保存鼠标最后位置，若完全未移动则保存中央值50，并以`line_timed_out`和`line_clicked`区分。
- 中途偏好报告练习和正式报告session开始前使用“确认”按钮，不再以空格进入；每题中央开始按钮与后续偏好横线位于同一屏幕高度，按钮正对横线中点。
- 正式基准总RT减去个人扫描阈值得到剩余决策RT；五个询问时间为“扫描阈值 + 决策RT的0/5至4/5”。
- 除浏览器要求的全屏入口外，实验过程页面均用空格推进；session之间强制休息60秒。

## 运行

浏览器打开 `index.html`。正式部署时建议通过HTTP服务器或脑岛平台运行。

可以通过URL传入被试编号：

```text
index.html?participant_id=P001
```

实验结束后自动下载CSV。原型使用脑岛提供的jsPsych 7与插件URL。
